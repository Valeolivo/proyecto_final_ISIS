# Propuesta de solución

## ¿Qué se propone?

Se propone desarrollar una aplicación web educativa dirigida principalmente a adultos mayores que utilizan la Sala de Internet del CLENA.

La aplicación web buscaría brindar conocimientos básicos para utilizar Internet de manera más responsable y autónoma, especialmente al momento de realizar búsquedas, consultar información y reconocer posibles riesgos digitales.

La plataforma utilizaría actividades cortas, como preguntas, encuestas y reflexiones, mediante las cuales los usuarios puedan aprender de manera sencilla sobre el uso responsable de Internet.

Como estudiantes de primer semestre, inicialmente se plantea desarrollar un prototipo de la aplicación utilizando Figma. Esto permitiría representar visualmente las diferentes pantallas y funcionalidades antes de realizar un desarrollo completo.

## ¿Para quién?

La solución está dirigida principalmente a los adultos mayores que utilizan la Sala de Internet del CLENA.

El proyecto busca apoyar especialmente a aquellos usuarios que pueden presentar dificultades para:

- Realizar búsquedas de información de manera autónoma.
- Reconocer información confiable.
- Identificar posibles riesgos relacionados con la seguridad digital.

## ¿Qué problema resuelve?

La propuesta busca contribuir a disminuir las dificultades identificadas en el uso autónomo de Internet.

Específicamente, busca fortalecer la capacidad de los usuarios para realizar búsquedas de información, reflexionar sobre la confiabilidad de los contenidos encontrados y reconocer algunas prácticas que pueden representar riesgos para su información personal.

De esta manera, se busca fomentar un uso más autónomo, responsable y seguro de Internet.

## ¿Cómo funcionaría?

Al ingresar a la aplicación, el usuario podría acceder a diferentes actividades cortas relacionadas con el uso de Internet.

Las actividades presentarían situaciones sencillas y preguntas para que el usuario seleccione una respuesta. Después de responder, la aplicación mostraría una explicación o reflexión sobre la situación.

Por ejemplo, se podría presentar una situación en la que el usuario deba decidir cuál de varias opciones corresponde a una búsqueda adecuada de información.

Después de responder, la aplicación mostraría una explicación sencilla sobre la situación.

Las actividades estarían organizadas de manera progresiva para facilitar el aprendizaje mediante la práctica y la reflexión.

## Prototipo

Como primera etapa del proyecto se propone utilizar Figma para crear un prototipo de la aplicación.

El prototipo incluye la simulación completa de las siguientes pantallas clave:

- *Pantalla de inicio:* Punto de entrada accesible con un botón claro para comenzar.
- *Menú principal:* Selección de temas mediante tarjetas ilustradas y tipografía de gran tamaño.
- *Actividades de aprendizaje:* Guías paso a paso diseñadas de forma lineal para evitar fatiga cognitiva.
- *Preguntas y encuestas:* Casos prácticos sobre seguridad en Internet con opciones de respuesta simples.
- *Resultados:* Mensajes de retroalimentación inmediata centrados en el refuerzo positivo.
- *Reflexiones y explicaciones:* Consejos sencillos sobre por qué una respuesta es correcta o segura.
- *Navegación general:* Botones visibles de "Volver" e "Inicio" para evitar que el usuario se sienta desorientado.

### Usabilidad y Accesibilidad

El diseño está pensado para adultos mayores de la Sala de Internet del CLENA, aplicando:
- *Alto contraste:* Colores claros y legibles.
- *Botones amplios:* Facilidad para hacer clic sin cometer errores.
- *Lenguaje cercano:* Libre de tecnicismos complejos de computación.

Esta representación visual permite validar la propuesta con la comunidad y sirve como base técnica para la futura etapa de programación.
El prototipo permitiría visualizar cómo funcionaría la solución antes de realizar su desarrollo.

## ¿Qué tecnología podría utilizarse?

La solución se plantea inicialmente como una aplicación web.

Para el prototipado se utilizará Figma como herramienta de diseño y representación visual.

En una etapa posterior, el prototipo podría convertirse en una aplicación web funcional con apoyo de estudiantes de semestres avanzados. Estos estudiantes podrían orientarnos para utilizar buenas prácticas de desarrollo y en la implementación de las funcionalidades.

## Proyección del proyecto

El objetivo a futuro es que el prototipo pueda evolucionar hacia una herramienta funcional que pueda ser utilizada por la comunidad del CLENA.

El trabajo de los nosotros, como estudiantes de primer semestre se concentraría inicialmente en comprender el problema, definir las necesidades de los usuarios y diseñar el prototipo.

Posteriormente, con el apoyo de estudiantes de semestres avanzados, se buscaría mejorar el prototipo y desarrollar una versión funcional.
