# Proyecto: Autoaprendizaje digital - CLENA
Nuestro proyecto consiste en diseñar una aplicación web educativa
dirigida a los adultos mayores que utilizan la Sala de Internet del
Centro de Eventos y Convenciones del Caribe (CLENA).

La propuesta busca brindarles herramientas y conocimientos básicos para
utilizar Internet de manera más autónoma, responsable y segura. Para
ello, se plantean actividades cortas e interactivas, como preguntas,
encuestas y situaciones prácticas, acompañadas de explicaciones
sencillas que les permitan aprender mediante la práctica y la reflexión.

La aplicación se enfoca especialmente en fortalecer las habilidades para
realizar búsquedas de información, reconocer contenidos confiables e
identificar posibles riesgos relacionados con la seguridad de sus
cuentas y datos personales. Además, esta aplicación web funciona como una guía 
de aprendizaje en la que hay documentos instructivos con los que las 
personas pueden tener un apoyo más sólido. 

## Objetivo: 
Diseñar una aplicación web educativa para fortalecer las habilidades
digitales de los adultos mayores que utilizan la Sala de Internet del
CLENA, promoviendo la búsqueda autónoma de información, el
reconocimiento de contenidos confiables y la prevención de riesgos
relacionados con la seguridad digital, mediante actividades interactivas
y explicaciones sencillas.
