Proyecto: Aplicación Web Educativa para Adultos Mayores (CLENA)
Fecha de la sesión: 16 de octubre de 2026
Plataforma: Microsoft Teams (Grabación de Backend)
Asistentes: Equipo de Desarrollo Backend y miembros del proyecto

1. Objetivo de la reunión
Establecer las bases técnicas, la arquitectura inicial y la sincronización con el equipo de backend para soportar las funcionalidades de la aplicación web educativa del CLENA (gestión de datos, autenticación y almacenamiento de actividades interactivas para adultos mayores).

2. Desarrollo de la reunión
Se discutieron los requerimientos técnicos iniciales necesarios para conectar la interfaz (prototipo en Figma) con la lógica del servidor y la base de datos.
Se definieron las tecnologías y endpoints principales para manejar los módulos educativos, encuestas y la retroalimentación de los usuarios.
Se establecieron los canales de comunicación y entrega continua entre el equipo de frontend/diseño y el equipo de backend.

3. Acuerdos y compromisos
Estructurar el repositorio de backend con las carpetas y dependencias necesarias para las pruebas iniciales.
Definir el esquema de datos para almacenar el progreso de los usuarios y las actividades interactivas.
Mantener reuniones de seguimiento periódicas para asegurar la integración correcta con el resto del equipo del proyecto.
