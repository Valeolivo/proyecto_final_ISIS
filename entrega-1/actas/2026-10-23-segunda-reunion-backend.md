Proyecto: Aplicación Web Educativa para Adultos Mayores (CLENA)

Fecha de la sesión: 23 de octubre de 2026

Plataforma: Microsoft Teams (Grabación de Backend - Segunda Sesión)

Asistentes: Integrantes del proyecto y equipo de desarrollo de backend aliado.

1. Objetivo de la reunión
Revisar el avance y la integración de los servicios de backend con el prototipo/interfaz de la aplicación, evaluar el estado de las estimaciones pendientes en las historias de usuario y definir los siguientes pasos para la sincronización de datos.

2. Desarrollo de la reunión
Se analizaron los avances en la conexión de las historias de usuario con la base de datos y la lógica del servidor.
Se discutieron los detalles técnicos sobre la persistencia de las actividades interactivas, encuestas y el registro de progreso enfocado en la usabilidad para adultos mayores.
Se resolvieron dudas respecto a las estimaciones de puntos y prioridades de las tareas compartidas con el equipo de backend.

3. Acuerdos y compromisos
Actualizar las estimaciones de las historias de usuario en conjunto con el equipo de backend.
Afinar los detalles de los endpoints necesarios para las pruebas funcionales de la aplicación web educativa.
Programar una nueva revisión de integración de código para verificar el flujo completo de datos.
