## Proyecto

CLENA Conecta: plataforma web interactiva para fortalecer las habilidades de búsqueda de información y seguridad digital en adultos mayores.

## Descripción

CLENA Conecta es una propuesta de solución tecnológica orientada a los adultos mayores que utilizan la sala de Internet del CLENA.

La propuesta busca fortalecer sus habilidades para realizar búsquedas de información en Internet y utilizar herramientas digitales de manera más segura.

La plataforma estaría diseñada con una interfaz sencilla, intuitiva y accesible, utilizando actividades interactivas y situaciones de la vida cotidiana para facilitar el aprendizaje.
