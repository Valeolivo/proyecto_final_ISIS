## Espacio estudiado

Sala de Internet del CLENA – Aduana de Barranquilla

## Descripción del proyecto

Durante la visita a la Sala de Internet del CLENA se realizó una observación del espacio, de las personas que lo utilizan y de las actividades que allí se desarrollan.

A partir de la observación se identificaron diferentes situaciones relacionadas con el uso de herramientas digitales. Entre ellas se encontraron dificultades para realizar búsquedas de información de manera autónoma, reconocer si la información encontrada en Internet es confiable e identificar posibles riesgos relacionados con la seguridad digital.

El proyecto se enfoca principalmente en los adultos mayores que utilizan este espacio y en la necesidad de fortalecer su autonomía para utilizar Internet de manera responsable y segura.

Como propuesta de solución se plantea una aplicación web educativa que, mediante actividades cortas, preguntas y reflexiones, permita a los usuarios aprender sobre búsquedas de información, confiabilidad de contenidos y seguridad digital.

Inicialmente se plantea desarrollar un prototipo utilizando Figma. Posteriormente, con apoyo de estudiantes de semestres avanzados, el prototipo podría evolucionar hacia una aplicación web funcional.
