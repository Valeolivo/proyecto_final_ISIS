Durante la visita se identificaron las siguientes situaciones:

- Algunos usuarios pueden presentar dificultades para realizar búsquedas de información en Internet de manera autónoma.
- Puede existir dificultad para reconocer si la información encontrada en Internet es confiable.
- Algunos usuarios pueden presentar dificultades para identificar posibles riesgos relacionados con la seguridad de sus cuentas o de su información personal.
- Se identificó la importancia de contar con formas sencillas de orientación para el uso de herramientas digitales.
- Se observó que el acompañamiento puede ser necesario para realizar algunas actividades digitales básicas.
## Usuarios observados

El grupo de usuarios que despertó mayor interés para el proyecto fueron los adultos mayores que utilizan la Sala de Internet.

Se consideró este grupo debido a que algunas actividades relacionadas con Internet pueden representar dificultades cuando se realizan de manera autónoma.
